CBeave Auction Platform

Solo full-stack project · 2026
Next.js 16 React 19 NestJS 11 Prisma PostgreSQL 17 Socket.IO Docker

An end-to-end real-time auction platform I designed and built alone: user registration, auction creation and scheduling, live bidding sessions, and post-auction results — with 200+ commits, full API documentation, and architecture decision records.

Technical highlight: Solved high-concurrency bidding by combining per-auction WebSocket rooms with serializable database transactions — so two simultaneous bids can't both read the same "current high bid" and silently overwrite each other — plus an anti-sniping mechanism that extends the auction clock when a bid lands in the final seconds.
